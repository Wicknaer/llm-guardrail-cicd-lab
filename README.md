# llm-guardrail-cicd-lab

PoC lab: LLM guardrails (input/output filtering) validated by **promptfoo** security tests,
embedded into CI/CD pipelines (GitHub Actions & Forgejo Actions).

> ⚠️ For educational / authorized testing only. All secrets and customer data in this repo are **fake**.

## Stack
- Ollama + `qwen2.5:1.5b`
- Python (FastAPI) target app with optional guardrails
- promptfoo `0.125.1`
